# Recipe Book Web Application

A responsive and interactive Recipe Book web application built using HTML, CSS, and JavaScript.

Users can store, manage, search, edit, and explore recipes with images, ingredients, preparation steps, and comments — all stored in browser local storage without any backend.

---

# Live Features

## Home Page
- Welcome section
- Navigation buttons
- Interactive landing page

## Add Recipe
- Add recipe name
- Add ingredients
- Add preparation steps
- Upload recipe image
- Form validation

## View Recipes
- Dynamic recipe cards
- Responsive grid layout
- View recipe details

## Recipe Modal
- Full recipe information
- Recipe image preview
- Numbered preparation steps
- Responsive modal popup

## Recipe Management
- Edit recipes
- Delete recipes
- Update recipes without re-uploading image

## Search Functionality
- Search by recipe name
- Search by ingredients
- Live filtering

## Comments System
- Add comments on recipes
- Persistent comments using local storage

## Navigation
- Back button support
- Browser history navigation

## Responsive Design
- Mobile friendly
- Tablet responsive
- Desktop optimized
- Scrollable layouts for small screens

## Local Storage
- Recipes saved in browser
- Data persists after refresh
- No backend required
